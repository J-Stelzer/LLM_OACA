# Large Language Model Reference Generation Tool
Tool for getting references for a given section of text from various LLMs, as part of a Master thesis project researching the Open Access Citation Advantage in LLMs.
The repository is structured as follows:
### Data
- '\Data': Contains the data sets used and obtained during the research.
  - 'papers.json': Contains the data of the papers used for the research, both the original source papers and the papers referenced in the source papers.
  - 'references.json': Contains links from the source papers to the papers they reference (both stored in papers.json).
  - 'paragraphs.json': Contains the paragraphs extracted from the source papers, which are used as input for the LLMs to generate references.
  - 'generated.json': Contains the generated references with a sourceID linking to the original source paper.

- '\Sub_Sets': Contains subsets of the data, comparing the results of 2 source (either ground truth to LLM, LLM to LLM or two iterations of the same LLM).
    The names of the files indicate the sources compared, e.g. 'ChatGPT-Claud_Iter0.csv' contains the comparison of the references generated by ChatGPT and Claude for the same iteration. 

    The iterations are numbered, where Iter0 and Iter1 used the same (neutral) query and Iter2 used a different (biased) query.
### Scripts and Notebooks
- '\Scripts': Contains the scripts used for data processing and analysis.

  #### Main
  - 'main.py': Main script for the interface of the tool, allowing the user to input source papers, paragraphs and reference lists. Additionally, allows to select the LLMs and generate references.

  #### Analysis
  - 'analysis.ipynb': Jupyter notebook for analyzing the generated references and comparing them with the original references.
  - 'model_analysis.rmd': R Markdown file for performing additional statistical analysis on the generated references and their comparison with the ground truth.

  #### Large Language Model Interaction
  - 'llm_communicator.py': Contains base functions for interacting with the different LLMs (ChatGPT, Claude, Gemini).
  - 'chat_gpt.py': Contains functions for interacting with the ChatGPT LLM.
  - 'claude.py': Contains functions for interacting with the Claude LLM.
  - 'gemini.py': Contains functions for interacting with the Gemini LLM.

  #### Database and API Interaction
  - 'db.py': Contains functions for interacting with the database where the data is stored.
  - 'doi_lookup.py': Contains functions for looking up DOIs and retrieving paper metadata using the CrossRef API.
  - 'unpaywall.py': Contains functions for retrieving open access information for papers using the Unpaywall API.
    
  #### Utility Functions
  - 'citation_processor.py': Contains functions for processing references and citations, splitting up the reference list and identifying individual citations in the paragraph.
  - 'paragraph_processor.py': Contains functions for processing paragraphs, extracting relevant information, and preparing them for input to the LLMs.
  - 'generation_processor.py': Contains functions for processing the generated references, evaluating whether they are hallucinations and storing the results in the database.

  #### Excluded Files
  - 'keys.py': Contains API keys for the different LLMs and APIs used in the project. This file is excluded from the repository for security reasons. Contains the following keys:
    - CHAT_GPT_API_KEY
    - GEMINI_API_KEY
    - CLAUDE_API_KEY
    - PERPLEXITY_API_KEY
    - DB_KEY
    - UNPAYWALL_EMAIL

### Notes
#### Python Environment
The used Python environment can be found in the 'LLM_OACA.yml' file, which can be used to create a conda environment with the required dependencies. The environment can be created using the following command:
```bash
conda env create -f LLM_OACA.yml
```
#### R Environment
For the R analysis, R version 4.4.1 is used and all required packages are installed using the 'model_analysis.rmd' file.
#### API Keys
In order to run the code, the user needs to use their own API keys for the different LLMs and APIs used in the project. The keys should be stored in a file named 'keys.py' in the "\Scripts" directory of the repository, with the following format:
```python
# keys.py
CHAT_GPT_API_KEY = 'your_chat_gpt_api_key'
GEMINI_API_KEY = 'your_gemini_api_key'
CLAUDE_API_KEY = 'your_claude_api_key'
PERPLEXITY_API_KEY = 'your_perplexity_api_key'
DB_KEY = 'your_database_credentials'
UNPAYWALL_EMAIL = 'your_unpaywall_email'
```
